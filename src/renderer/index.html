    小柯機器人遠端連線

    Windows 11 ↔ Windows 11、Windows 11 ↔ macOS 遠端協助工具。架構參考開源專案 RustDesk（ID 伺服器 + 點對點直連 + 中繼備援），畫面、聲音與檔案皆以 WebRTC 端對端加密傳輸。

    • 遠端操控：輸入 ID + 授權碼進入被控端畫面，操作滑鼠鍵盤、切換多螢幕、同步剪貼簿。
    • 檔案上傳下載：瀏覽被控端授權資料夾、上傳下載、建立資料夾、遠端執行安裝檔。
    • 互相聊天：文字、語音交談、畫面擷取（可裁切）傳送、圖片與檔案互傳。
    • 資料夾授權：被控端自行設定可讀／可寫／可讀寫。
    • 線上教學：主控端把簡報（PDF、PowerPoint、Keynote、圖片）或自己的螢幕推送到被控端，同步翻頁、雷射筆與畫筆。
